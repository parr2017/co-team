# 计划模板（Plan Template）

复制对应模板到任务目录，按需填写删除。档级判定见 SKILL.md 第 1 节。

---

## 模板一：完整计划（B/C 档）

````markdown
# 任务计划：<任务名>（<日期>）

## 人话摘要

- **解决什么问题**：<用户/业务的具体痛点>
- **做什么**：<一句话概括动作>
- **怎么做**：<一句话概括方式，如"改 X 模块的 Y 逻辑，共 N 步">
- **做完后效果**：<用户能感知的变化 / 可验收标准>

## 1. 背景与目标

<问题从哪来、用户要什么、成功标准（可验收）>

## 2. 现状与约束

- 现状：<相关文件/模块现状，附 文件:行号>
- 已有实现：<可复用的部分>
- 约束：<不能动的、依赖的、时间限制>

## 3. 方案与取舍

| 方案 | 做法 | 优点 | 代价/风险 |
|---|---|---|---|
| A（推荐） | ... | ... | ... |
| B | ... | ... | ... |

推荐 A，理由：<...>
（若只有一个方案：说明为什么不需要比较）

## 4. 影响面

- 受影响文件：<清单>
- 受影响接口/数据：<清单>
- 需同步的文档：<清单>

## 5. 步骤

| # | 做什么 | 怎么做（文件+方式） | 为什么（解决什么问题） | 怎么验证 | 状态 |
|---|---|---|---|---|---|
| 1 | ... | ... | ... | ... | ⬜ |
| 2 | ... | ... | ... | ... | ⬜ |

## 6. 风险与回滚

| 风险 | 概率/影响 | 预防 | 翻车了怎么办 |
|---|---|---|---|
| ... | ... | ... | ... |

## 7. 决策点（需用户拍板）

- [ ] <问题>？默认：<选项A>，备选：<选项B>

## 8. 交付物清单

- [ ] 代码
- [ ] 测试
- [ ] 文档 / changelog
````

## 模板二：微型计划（A 档）

四问一句话，不落盘、不建进度表，对话里直接给出：

```
解决什么问题：<...>
做什么：<改哪个文件、改什么>
为什么：<为什么这么改>
怎么验证：<编译通过 / 跑通 X / 输出 Y>
```

示例：

```
解决什么问题：列表页导出按钮点了没反应
做什么：在 frontend/src/views/List.vue 补上 onClick 绑定，调用已有的 exportApi
为什么：上次重构时删掉了绑定但没接回来
怎么验证：本地点导出，文件正常下载
```

---

## 填写提醒

- "怎么做"必须具体到文件路径 / 命令，禁止"相关文件""适当调整"
- "为什么"要回答"为什么这么改、为什么不选别的"，不是复述"做什么"
- 步骤状态只用三档：⬜ 未开始 / 🔄 进行中 / ✅ 完成，禁止提前勾选
- 现状里的每条信息标注类型：事实（附证据）/ 假设（待验证）/ 未知（需调研或问用户）
