# Co-Team Web UI 产品化改版方案计划

> 日期：2026-09-18 · 状态：**已落地**（db7882a→94dc8b0 七步 commit；验收记录见 开发路线.md 同日章节）
> 预览：`docs/ui-redesign/preview.html`（三屏+设置 overlay × 双主题）
> 约束：**功能零丢失**（见 §4 保全清单）、**mobile 本期不动**（用户拍板，web/mobile 代码完全隔离已验证）

## 0. 人话摘要

**解决什么问题**：web 端像实验草稿——群聊字太小看不清、页面两侧大片留白、组件质感混用、主页没有产品感。
**做什么**：按已拍板的「暗色终端 IDE 风」深度重构 web 端壳层 + 4 个主页面 + 11 个全局对话框，**所有现有功能保留**。
**怎么做**：7 步推进（token → 壳层 → 群聊 → 任务域 → 主页 → 全局清洗 → 验收），每步独立 commit 可回滚。
**做完效果**：满宽三栏工作区、消息正文 14px、9px 小字绝迹、暗色=暖橙 / 亮色=蓝、Element Plus 与手写控件一个质感。

## 1. 已拍板决策记录

| 决策点 | 结论 |
|---|---|
| 视觉基调 | 暗色终端 IDE 风（深炭底 / mono 数字 / 高对比 / 克制用色） |
| 主题策略 | **双主题同等精修**；强调色与主题绑定：**暗=暖橙 #ff9349、亮=蓝 #2f6fed**（不做独立强调色切换） |
| 组件底座 | **保留 Element Plus 深度调参**（`--el-*` 全量映射新 token），手写控件按同一 token 重绘 |
| 布局 | 满宽三栏工作区，去掉 1180px 居中与两侧留白；消息正文列宽上限 1160px（宽屏≠行宽无限） |
| 群聊详情面板 | **常驻可收**（IDE inspector 形态），替代「点详细才滑出」 |
| 设置 | overlay 浮层面板形态（12px 圆角 + 浮层阴影 + 背景压暗），tab 结构保留 |
| 字号 | 正文 14px/行高 1.6，辅助 12px，meta 最小 11px；**9px/10px 全部消灭** |
| mobile | 本期不动（用户拍板）；web/mobile 代码隔离已验证，风险=token 值分叉，接受 |

## 2. 设计语言规范（token 体系，落盘到 `web/src/styles/tokens.css`）

```css
/* 色彩三阶层 + 语义色（暗色默认 / html.light 覆盖） */
--bg-page/--bg-panel/--bg-raised/--bg-overlay/--bg-inset   /* 底色五层 */
--line/--line-strong                                        /* 发丝线 */
--text-1/--text-2/--text-3                                  /* 文字三级 */
--accent（暗:#ff9349 / 亮:#2f6fed）--ok/--warn/--danger
--ag-*（agent 身份调色板，沿用 agentColor.ts 9 色不动）

/* 字号阶梯（9-13px 二十余档 → 7 档） */
--fs-meta:11px  --fs-aux:12px  --fs-body:14px  --fs-sub:15px
--fs-title:16px --fs-h2:18px   --fs-h1:22px

/* 几何 */
--r-ctl:6px  --r-panel:10px  --r-float:12px   /* 阴影只给浮层 */
--shadow-float（唯一阴影 token）
--sp-1:4px --sp-2:8px --sp-3:12px --sp-4:16px --sp-5:24px
--measure:1160px  --disc-w:264px  --detail-w:360px
```

字体不变（系统 UI 字 + JetBrains Mono）；**mono 只用于数字/ID/路径/token 数**（IDE 感来源，非全文 mono）。

## 5. 影响面

- **改**：App.vue、`web/src/styles/tokens.css`（新）、ApprovalInboxView + 34 组件中约 20 个
- **不改**：`server/**`、`mobile/**`（本期）、`web/src/api/**`、`web/src/composables/**`、路由机制（v-if 渲染保留）、`utils/agentColor.ts`（调色板沿用）
- **依赖**：不新增（EP/echarts/marked/hljs 原样）

## 6. 风险与回滚

1. **功能遗漏**——最大风险。对策：§4 清单即验收清单，每步完成后按区打勾；步骤 7 全量回归。
2. **EP 调参冲突**——沿用 App.vue 既有 `--el-*` 覆盖层机制扩展，不引入新依赖；翻车回滚单步 commit。
3. **字号放大→密度下降**——meta 信息不跟随放大（11px 下限），保住信息密度。
4. **宽屏超长行**——正文列宽上限 1160px。
5. **mobile token 分叉**——本期接受；mobile 有独立 token 副本，后续单向移植。
