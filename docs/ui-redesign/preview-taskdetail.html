移动端改版要点

  • Hero 头卡：状态药丸 + 标题 + 元信息 chips + 进度条/剩余时间，一屏内先回答"现在怎样"。
  • 紧凑步进器：澄清→审核→执行→完成，与 web 同构。
  • 三分区：对话 / 执行详情 / 管理，治理类内容从"执行详情"里拆出来，不再混着刷。
  • 节点 rail 卡：运行中节点带心跳 chips（模型/轮次/退避），失败节点显示阻塞原因。
  • 阻塞问答补齐NEW：现版 mobile 没有"阻塞问答"，管理页补上提问卡 + 行内回答，与 web 对齐。
  • 待审批命令/提案置顶：需要人拍板的事永远排在管理页最上面，带红色角标。

Web 端改了什么（对照现版）

  • 01弹窗头一体化：状态药丸 + 标题 + 元信息 chips（ID/工作区/分支/等级/tok/成本/ETA）+ 大进度条 + 主操作（合并/文档/产出/取消）收进同一头部；原"元信息一行小字 + 散按钮"重组为可扫读的 chip 行。
  • 02左侧竖导航取代横向 tabs：任务频道 / 实时驾驶舱 / 事件归档 / 管理；管理入口带待办红标（待审批命令+问答+提案合计），有事直接可见。
  • 03阶段步进器精修：✓/当前步光环/连接线通过态着色，与 mobile 同构。
  • 04节点轨道改为站卡 + 左侧圆点轨：运行中节点保留心跳 chips（模型/轮次/token/退避）与生成直播打字行，选中节点强调色渐变高亮；成员 chips 精修为胶囊带运行点。
  • 05节点详情分区卡化：EXECUTION 执行档案（轮次/耗时/上下文/知识命中/工具 chips）/ SUMMARY / CHANGES / DEFECTS（严重度 chip + 转修复任务）/ 时间线，各区块独立卡片，标题统一 mono 小字距。
  • 06实时驾驶舱：三卡（滚动阶段/验收清单/执行动态计数）+ 终端风事件流，高亮当前节点事件。
  • 07事件归档：分类 seg + 搜索框 + 计数右对齐，列表加节点/agent 侧标 chips；保留"显示高频细节"与加载更多（预览未展开）。
  • 08管理页双列卡片：待审批命令（红色 alert 卡置顶）/ 阻塞问答 / 监督者提案 / 执行策略 / 主模型 / 快照 / 全局目标；全部现有操作（批准/拒绝/回答/补授白名单/换模型/回滚/编辑目标）保留。
  • 09功能零删减：澄清卡、零产出上游级联重启、门禁测试行、测试报告、协同文档/实时产出弹窗等全部保留原位，仅视觉重组。
  • 10与任务中心同语言：状态药丸/mono 数字/色轨/卡片圆角与任务中心改版完全同一套 token。
