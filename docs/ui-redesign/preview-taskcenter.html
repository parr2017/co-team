移动端改版要点

  • Hero 卡：待我处理数字放大 + 呼吸闪烁（有事项时），强调色渐变描边；Token/成本保持 mono 对齐。
  • 状态药丸：与 web 端同款 pill（暗=橙系强调），执行中带脉冲点，一眼可辨"在途 vs 需要你"。
  • 会话式行：保留微信消息流隐喻；digest 行区分已读/未读（未读加粗提色）；徽标用红色计数（审批+澄清）。
  • 失败行内联重启：保留现有 mini 重启按钮，位置收进 meta 行右侧与徽标、id 对齐。
  • 队列泳道：阻塞态用危险色渐变头 + 恢复按钮，与 web 端同构。
  • FAB：右下角新建任务入口（强调色圆形），替代散落在导航栏的 +。

Web 端改了什么（对照现版）

  • 01工具栏一行收齐：标题 + 实时连接指示 + 范围切换（segmented control 取代裸复选框"包含项目任务"，切换即时生效并带计数）+ 搜索框（含回车提示）。原来散落三处的控件合并为一个焦点行。
  • 02统计带升级为数据驾驶舱：7 个状态卡（左侧色轨 + 大号 mono 数字 + 口径注释），点击过滤列表；选中卡有强调色渐变。原 chipbar 的小药丸层级弱、数字不突出。
  • 03任务列表从"裸表格"改为行卡：每行是带圆角边框的独立卡片，左侧 3px 状态色轨（执行中橙 / 待办黄 / 失败红 / 完成绿），hover 抬升；状态列改为带底色的状态药丸。
  • 04失败原因前置：不再藏在最后一列，直接显示在任务标题下方（mono 危险色），宽屏一眼看到"为什么红"。
  • 05操作按钮分层：主操作（详情/审核计划/回复澄清/重启）常驻高亮，次要操作（日志/取消/更多）半透明常驻、hover 提亮，降低视觉噪音；"更多"收敛为 ⋯ 图标按钮。
  • 06执行 Agent 列增强：头像加身份色 + 执行中脉冲光环，与工作台 Agent 视觉语言一致。
  • 07表格/卡片双视图（可选）：宽屏表格密度高，卡片视图适合触屏笔记本与投屏演示；切换状态记忆在 localStorage。
  • 08队列泳道：阻塞态左侧危险渐变 + 恢复/清空按钮右对齐，语义与 web 现版一致只做视觉精修。
  • 09功能零删减：现有全部操作（详情/日志/拓扑图/审核计划/回复澄清/重启/取消/删除/分页/搜索/范围切换/统计口径跟随）一个不少，只是重新组织与美化。
  • 10双端同构：状态药丸、色轨、徽标、队列样式 web 与 mobile 共用同一套 token 语义，后续改一处两端同步。
