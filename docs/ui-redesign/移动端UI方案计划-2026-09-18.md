# Co-Team 移动端 UI 产品化改版方案计划

> 日期：2026-09-18 · 状态：**已落地**（六步 commit；验收记录见 开发路线.md 同日章节）
> 预览：`docs/ui-redesign/preview-mobile.html`（8 屏 × 双主题，390×844 手机壳）
> 约束：**功能零丢失**（§4 保全清单）、**独立于 web**（mobile 刻意不依赖 web/src，改版后依旧）

---

## 0. 人话摘要

**解决什么问题**：mobile 端延续 web 端的「草稿感」——卡片糊墙、字号偏小、Vant 默认风格与产品定位不符。
**做什么**：按与 web 同套的「暗色终端 IDE」设计语言重构 mobile 端 14 个视图的视觉层，功能与交互全部保留。
**怎么做**：Vant 深度调参（`--van-*` 变量映射同套 token）+ 少量结构重绘，6 步推进、每步独立 commit。
**做完效果**：与 web 一致的暗橙/亮蓝双主题、正文 14px、列表行化（去卡片马赛克）、底部 sheet 统一质感。

## 1. 已拍板决策

| 决策点 | 结论 |
|---|---|
| 视觉基调 | 与 web 同套：暗色终端 IDE 风；**暗=暖橙 #ff9349 / 亮=蓝 #2f6fed** 绑定 |
| 组件底座 | **保留 Vant 深度调参**（对应 web 保留 EP 路线），手写控件按同 token 重绘 |
| token 策略 | `mobile/src/style.css` 升级为完整 token 副本（不与 web 共文件，维持刻意隔离），值与 web 语义一致 |
| 时机 | mobile 代码移植在 **web 7 步验收后启动**，作为独立任务；方案与预览先行 |

## 2. 设计语言（mobile 适配）

- 底色三阶层 / 发丝线 / 语义色 / agent 调色板：与 web **同值**（见 web 方案 §2）
- 字号阶梯同 web：正文 14 / 辅助 12 / meta 11（9-10px 绝迹）；移动端行高 1.55，触控目标 ≥44px
- 几何：控件 6px、cell 组 10px、**底部 sheet/弹层圆角顶部 12px**、阴影只给浮层
- Vant 映射：`--van-nav-bar-*`、`--van-tabbar-*`、`--van-cell-*`、`--van-button-*`、`--van-popup-*`、`--van-tag-*` 全量对接 token
- 结构语言：**cell 行 + 发丝线**替代卡片马赛克；列表页 tabbar 5 项（任务/讨论/项目/审批/我的）暗面板 + accent 选中态 + mono 徽标

## 5. 影响面与风险

- **改**：`mobile/src/style.css`、App.vue、14 视图 + 6 组件的 style 块（结构改动仅群聊/任务详情局部）
- **不改**：`server/**`、`web/**`、`mobile/src/api|composables/**`、路由结构、Vant 依赖版本
- **风险**：Vant 变量覆盖不全导致局部默认亮色残留 → 步骤 1 以「暗色全量走查」收口；字号放大→长列表滚动变长（接受）；agent 调色板/agentColor.ts 镜像同步（手写副本，移植时人工对照 web）
- **回滚**：每步独立 commit
