## 人话摘要

- **解决什么问题**：①对话"没反应/突然断头"；②AI 幻觉严重（编造事实、谎称完成）；③项目无记忆、经验蒸发；④上下文注入/裁剪/压缩原始。
- **做什么**：P0 流畅度止血 → PH 反幻觉与 harness 强化 → P1 项目概念+经验沉淀 → P2 上下文引擎。
- **怎么做**：借鉴星瑶已验证方案（终态事件纪律、进展熔断、四级水位线、四类记忆、防注入校验），落到具体文件，每步独立验证。
- **效果**：发消息必有反馈；讨论必有收场白；断言必须有证据支撑；经验自动变确认卡入库；长对话分级瘦身且可找回。

## 跨阶段不变量

1. 缓存优先：静态前缀+append-only+确定性折叠+字节稳定渲染。
2. 改写只落存储层，请求路径不动历史中间字节。
3. 错误结果永不裁剪；尾部保护区永不改写。
4. 终态唯一：一 turn 恰好一个终态帧。
5. 超时不判死：600s 硬上限只针对"无任何字节"的确定性信号。
6. 目录监狱；web/mobile 双端一致。

## 风险与回滚

| 风险 | 预防 | 回滚 |
|---|---|---|
| 水位线破坏前缀缓存 | 改写只落存储层；字节稳定断言 | revert 单提交 |
| 断言门误伤 | 只拦零工具轮；有证据放行；纠正有界 | 配置开关降级 |
| 熔断误杀调查 | 48 读取预算；真实进展重置 | 阈值调大或关闭 |
| 确认卡打扰 | 每 turn ≤1 张；复盘不入卡 | 关闭开关 |
| seq 改 schema | 只增字段；旧消息按 id 兜底 | 整体旁路 |
| embedding 不稳 | Hybrid 天然降级 | 配置关闭 |
| P0+PH 同文件干扰 | 状态机先行、门后行，分 commit | 分 commit revert |
