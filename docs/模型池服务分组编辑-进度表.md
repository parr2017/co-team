# 模型池「服务分组」编辑 — 任务进度表（B 档）

日期：2026-09-10　需求：模型配置界面太死板——同一个 baseUrl、同一个 apikey 下应可配置多个不同模型。

## 设计决策

- **存储契约不变**：`config.yaml` 的 `model_pool` 保持扁平数组（`name` 是调度器唯一键，ModelPool/scheduler/llm/节点模型钉选全部依赖）。不迁移、不影响运行时。
- **分组是编辑视图**：设置界面按 `base_url + api_key` 把条目归组为「服务接入点」卡片；组头部编辑公共字段一次，同步到组内所有模型；保存时展平回扁平数组。
- **上游模型发现**：新增 `POST /api/config/upstream-models`（body: base_url+api_key），OpenAI 兼容 `GET {base_url}/models`，界面「拉取模型」后勾选批量导入，免手打模型名。
